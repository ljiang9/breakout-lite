# breakout-lite

极简打砖块：球速、墙/砖块/挡板反弹、砖块血量、生命数。纯标准库，无第三方依赖。

## 玩法

- `python3 -m breakout_lite` — 交互模式：`a` 左移 / `d` 右移 / `q` 退出（行输入，每步回车）
- `python3 -m breakout_lite --auto` — 无头 AI 演示（挡板自动追踪球）
- `python3 -m breakout_lite --auto --frames 5000 --seed 42 --verbose` — 指定帧数/种子/打印棋盘

规则：顶行砖块 2 血，其余 1 血；打掉砖块 +100（打掉血皮 +50）；球掉出底线扣 1 命，共 3 命；清光砖块获胜。

## 验证记录

- `py_compile` 通过
- 单元测试（真实执行）：砖块被击中移除/扣血 ✅；挡板反弹（vx 按击球位置变化）✅；掉出底线扣命、3 命耗尽结束 ✅；左右墙/顶墙反弹 ✅；清光砖块判胜 ✅
- `--auto --seed 42` 2000 帧正常结束

## 已知局限

- 无实时键盘输入：交互是"每行一个命令"的回合制；`--auto` 只是无头演示
- AI 挡板完美追踪，演示几乎不掉球；调速/制造失误不在范围内
- 无音效、无存档、无最高分
